# ADR-0007: 해시 체인 서명 영수증

- 상태: Accepted · 2026-10-14

## Context
에이전트 거래 분쟁은 "사용자가 무엇에 동의했고, 에이전트가 무엇을 했는가"를 제3자(PSP·카드사·규제기관)가 검증할 수 있어야 해결된다. AgentPass 자신도 신뢰 대상이 되어서는 안 된다.

## Decision
모든 보안 이벤트를 append-only 해시 체인으로 기록하고 1분마다 AgentPass 키로 체크포인트를 서명, 외부 투명성 로그에 게시한다. 페이로드는 해시만 체인에 넣어 개인정보 삭제 요청과 양립.

## Alternatives
- 퍼블릭 블록체인 기록: 비용·지연·개인정보 리스크.
- 일반 DB 감사 로그: 사후 조작 탐지 불가.

## Consequences
- (+) 사후 조작 탐지, 독립 검증 가능한 Evidence Bundle.
- (−) 리전별 체인 순서화로 쓰기 병목 → 리전·샤드별 체인 + 상위 체크포인트로 확장.
